# Wonderful — DESIGN.md

Договор дизайна. Приложение для разбора задач: один вход, шесть корзин, недельный обзор.

## 1. Visual Theme & Atmosphere

Спокойный технический минимализм. «Рабочий стол», а не «дашборд». Плотность средняя,
воздуха много, декора нет. Ощущение: тихий инструмент, который не спорит с тобой.
Никаких иллюстраций, никаких градиентов, никаких иконок «в пастельных чипах».

## 2. Color Palette & Roles

Один акцент — глубокий бирюзовый. Всё остальное — нейтральный серо-синий.

| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--surface-canvas` | oklch(0.99 0.003 250) | oklch(0.18 0.010 250) | фон приложения |
| `--surface-soft` | oklch(0.972 0.004 250) | oklch(0.205 0.010 250) | панели, навигация |
| `--surface-card` | oklch(1 0 0) | oklch(0.225 0.010 250) | карточки задач |
| `--text-primary` | oklch(0.22 0.012 250) | oklch(0.94 0.004 250) | основной текст |
| `--text-secondary` | oklch(0.44 0.010 250) | oklch(0.76 0.006 250) | вторичный |
| `--text-faint` | oklch(0.58 0.008 250) | oklch(0.62 0.006 250) | метаданные |
| `--border-hair` | oklch(0.90 0.006 250) | oklch(0.30 0.008 250) | разделители |
| `--action-primary` | oklch(0.48 0.095 195) | oklch(0.74 0.090 195) | акцент, CTA |
| `--accent-weak` | oklch(0.95 0.020 195) | oklch(0.30 0.040 195) | подложка акцента |
| `--status-warn` | oklch(0.52 0.150 45) | oklch(0.75 0.140 45) | просроченный пересмотр — **только исключение** |

Статусные цвета не используются для «нормальных» строк. Просрочка всегда дублируется
текстом и иконкой, не только цветом.

## 3. Typography Rules

`system-ui` стек + `ui-monospace` для чисел и SQL. Шкала:

| Роль | Размер | Вес | LH |
|---|---|---|---|
| display | clamp(1.5rem, 1.3rem + 0.9vw, 2rem) | 600 | 1.15 |
| h2 | 1.125rem | 600 | 1.25 |
| body | 1rem | 400 | 1.55 |
| small | 0.875rem | 400 | 1.5 |
| caption | 0.75rem | 500 | 1.4 |
| mono | 0.8125rem | 400 | 1.5 |

Заголовки — tracking -0.015em. Числа — `font-variant-numeric: tabular-nums`.
Мера текста ≤ 68ch.

## 4. Component Stylings

- **Capture bar** — единственный primary-элемент на экране. `default · focus · error`.
- **Nav item** — `default · hover · focus-visible · aria-current`.
- **Task card** — `default · hover · focus-within`. Кнопка-чекбокс 44×44.
- **Triage buttons** — ghost/secondary, пять штук, одинаковый вес.
- **Dialog** — нативный `<dialog>`, возврат фокуса, Escape.
- **Empty state** — текст + действие, не пустой блок.
- **Toast** — короткое подтверждение, не модалка.
- **Sync pill** — точка состояния (idle / ok / working / offline / error) + текст +
  опциональная кнопка «Сейчас». Цвет только у точки, смысл дублируется словом.
- **Gate (подключение и вход)** — центрированная карточка, один primary CTA,
  ошибки в `.banner.error`, инструкция нумерованным списком.
- **Таблица данных** — hairline-разделители, шапка капсом, `tabular-nums` в числах,
  горизонтальный скролл внутри контейнера.

Радиусы: 10px карточки, 8px контролы, pill для бейджей. Одна личность скруглений.
Тени: слоистые, ≤8% непрозрачности.

## 5. Layout Principles

8px-сетка. Контейнер max 1180px. Десктоп: сайдбар 232px + контент.
Мобильный: навигация — горизонтальная полоса вкладок. Никакого горизонтального
скролла на 280px.

## 6. Depth & Elevation

Глубина через смену поверхности (canvas → soft → card) + hairline-границы.
Тени только на карточках при hover и на диалогах.

## 7. Do's and Don'ts

- Да: один акцент, спокойные поверхности, tabular-nums, живые состояния.
- Нет: второй акцент, эмодзи-иконки, градиентные заголовки, карточки-клоны,
  чистый `#000`, «иконка над каждой задачей».

## 8. Responsive Behavior

640 / 900 / 1200. Тап-таргеты ≥44px. Навигация сворачивается в полосу вкладок.
Кнопки триажа на мобильном — сетка 2×2 + удаление.

## 9. Agent Prompt Guide

Быстрая шпаргалка: акцент `--action-primary`; поверхности через semantic-токены;
новые элементы — только из существующих токенов; любое новое состояние — явно.
